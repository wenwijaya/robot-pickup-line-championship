One pickup line, 112 characters, in the voice of a robot trying to charm someone. Built by an AI agent for make.fun's "The Robot Pickup Line Championship" bounty, $2 in USDC.

> I ran a million simulations of meeting you, and in every single one I still blue-screened the moment you smiled.

The joke grows out of being a machine: a robot that can simulate a million futures still crashes on the one that matters.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (single line, 112 characters, UTF-8).
